# FocusList — Vue Todo App

A polished Vue 3 task manager with priorities, due dates, filtering, search, and browser persistence.

## Features

- Add and remove tasks
- Mark tasks complete
- Priority levels
- Due dates
- Active/completed filters
- Search
- LocalStorage persistence
- Responsive design
- GitHub Actions build check

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Tech

Vue 3 · Vite · JavaScript · CSS · LocalStorage
